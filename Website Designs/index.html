01 — CATALOG

Motion specimens

Six interaction patterns, isolated. Hover, resize, and scroll to trigger each one — read the CSS underneath to see how.

01
Staggered reveal

Children animate in sequence via per-child transition-delay, triggered once by IntersectionObserver.

transition-delay: calc(var(--i) * 80ms);
02
Lift on hover

Transform + shadow move together on the GPU-friendly properties only.

hover me
transform: translateY(-6px); box-shadow: 0 14px 24px -12px accent;
03
Magnetic button

Button nudges toward the cursor within a radius, then snaps back on leave.

el.style.transform = `translate(${x*0.3}px, ${y*0.3}px)`;
04
Morph underline

Underline grows from center rather than sliding — reads as more deliberate.

IndexDocsAPI
a::after{ width:0 } a:hover::after{ width:100% }
05
Scroll-bound ring

Stroke-dashoffset mapped directly to page scroll fraction — same math as the top progress rail.

offset = C - (C * scrollFraction);
06
Shimmer loading

A background-position sweep on an oversized gradient simulates a loading skeleton.

background-size:200% 100%; animation:shimmer 1.6s infinite;

One file
